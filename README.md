Built a Drowsy Driver Detection System using computer vision to identify signs of driver fatigue in real time and alert them before an accident occurs. The goal is to increase road safety by monitoring facial cues like eye closure and yawning frequency.


Tech Stack
Python
OpenCV
Dlib(face landmark detection)
CNN model / Eye Aspect Ratio (EAR) logic
Alerts: Buzzer 

How It Works
A camera continuously captures the driver's face.
The model detects facial landmarks (eyes, mouth).
If drowsiness persists for a threshold duration, the system triggers an alarm.
